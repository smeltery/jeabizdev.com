# Brand provenance

The site preserves the established JEA name, DNA mark, and blue palette.

Source: [JEA BizDev Consulting](https://www.jeabizdev.com), inspected October 12, 2026.

- `public/brand/mark.svg` contains the exact DNA path geometry extracted from the live header’s inline SVG. The live mark is the Lucide DNA icon, with stroke color `rgb(37, 99, 235)` / `#2563EB`.
- The live wordmark reads “JEA BizDev Consulting” and uses charcoal `#1F2937`. The header renders that text beside the source mark; downloadable wordmarks package the same identity in SVG form.
- Primary blue: `#2563EB`; blue hover: `#1D4ED8`; white: `#FFFFFF`; light blue: `#EFF6FF`.
- Supporting navy `#172B50` and dark navy `#111F38` provide contrast in the globe, contact band, and footer. Light-blue accents are `#93C5FD`.
- Georgia headlines and locally hosted Geist body text establish the redesigned editorial layout while retaining JEA’s name, icon, and blue identity.
